## [Cloudflare Open-Sources BEACON: Billions of Real-User Web Performance Measurements](https://blog.cloudflare.com/how-fast-is-the-web/) ⭐️ 9.0/10

Cloudflare has open-sourced the BEACON dataset, making billions of anonymized Real User Monitoring \(RUM\) performance records publicly available on Google BigQuery for analysis. This dataset provides developers and researchers with unprecedented access to real-world web performance data, enabling evidence-based optimization and deeper understanding of user experience across diverse environments. The dataset includes Core Web Vitals, soft navigation metrics, and performance breakdowns across browsers and regions, offering insights into loading performance, interactivity, and visual stability.

rss · Cloudflare Blog · Sep 28, 22:43

**Background**: Core Web Vitals are a set of metrics that measure real-world user experience for loading performance, interactivity, and visual stability of web pages, and are essential for delivering great user experiences. Real User Monitoring \(RUM\) captures real-time data from actual users visiting a website, helping identify performance issues and optimize user experience by analyzing how pages load and behave in diverse environments. Google BigQuery is a managed, serverless data warehouse product that enables scalable analysis of massive datasets through SQL queries and built-in machine learning capabilities.
